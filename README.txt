# Página para pedirle que sea tu novia ❤️

## Estructura
- `index.html` → página principal
- `styles.css` → todos los estilos
- `script.js` → menú, carrusel, pregunta y música
- `assets/photos/foto-1.jpg` a `foto-5.jpg` → reemplázalas por tus fotos
- `assets/photos/placeholder.svg` → imagen de respaldo cuando todavía no has puesto una foto
- `assets/music.mp3` → opcional; agrega tu canción con este nombre

## Cómo usarla
1. Descomprime la carpeta.
2. Reemplaza `foto-1.jpg` hasta `foto-5.jpg` por las fotos que quieras.
3. Opcionalmente agrega una canción llamada `music.mp3` dentro de `assets`.
4. Abre `index.html` en Chrome, Edge o Firefox.

## Cómo personalizar el texto
Puedes editar directamente `index.html`. Las frases principales están en la sección `hero`, los “términos y condiciones” están dentro de `terms-card` y la pregunta final está en `question-section`.

## Detalles incluidos
- Diseño romántico moderno y responsive.
- Encabezado fijo.
- Menú lateral de tres rayas.
- Sección de “términos y condiciones” para una relación sana.
- Carrusel automático y manual de fotografías.
- Animaciones suaves.
- Botón con música opcional.
- Sección final con la pregunta “¿Quieres ser mi novia?”.
- Sin dependencias externas de JavaScript.
